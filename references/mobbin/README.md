# Referencias Mobbin — FocusFlow

Usa estas imágenes como material de análisis visual, no como assets de producto. Los archivos fueron descargados desde las URLs públicas devueltas por la única búsqueda Mobbin; conserva una implementación original y no copies marcas, logos, textos ni layouts literalmente.

## 01 — Opal: Today / progreso
- **Archivo / origen:** `01-opal-today-progress.jpg` · https://mobbin.com/screens/e461d9ca-2fa8-46c4-ab58-a164142bf551 · imagen: https://mobbin.com/api/mcp/short/hGQorYH8
- **Patrón y jerarquía:** resumen diario con título Today, métricas apiladas, barras comparativas y reporte final.
- **Navegación / composición:** back y navegación inferior; lista vertical con mucho aire, líneas finas y una card grande de resumen.
- **Densidad / paleta / tipografía:** densidad baja-media; carbón casi negro, blanco y verde/teal; sans compacta, números y estados con alto contraste.
- **Spacing / radios / sombras:** márgenes generosos, card de radio alto y elevación muy sutil.
- **Iconografía / cards / estados:** iconos mínimos, barras de progreso y estados cualitativos; el progreso puede animarse suavemente.
- **Qué no copiar:** fondo negro, métricas de screen time, copy, branding Opal ni composición exacta.

- **Iconografía / cards / estados:** play/pause, skip y progreso lineal; transición clara entre activo, pausado y terminado.

## Síntesis visual para FocusFlow
Extraer: el foco métrico de Opal, el timer austero de Life Reset, las filas táctiles de Granola, la estructura de tareas de Gemini y el CTA persistente de Liven. Dirección propia: **papel cálido + tinta carbón + lima eléctrica de energía**, con tarjetas suaves, tipografía sans precisa y movimiento mínimo de progreso. No se necesitan fotografías ni ilustraciones reales para este MVP.
